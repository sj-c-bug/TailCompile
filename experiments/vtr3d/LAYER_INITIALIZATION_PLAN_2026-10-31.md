# 下一轮 3D 方法改进：显式分层、垂直压力与原生 GP 衔接

日期：2026-10-31。依据代码：`df2b4edca`；依据实测：006 repair。状态：**下一轮设计计划，尚未实现或运行**。拟用独立 `development_007_layer` 批次，实际运行前生成包含源码、数据、后端和参数哈希的机器可读协议。

本文接替旧主方案中“联合 layer/leaf＋三臂 480 次”作为下一步执行安排；旧协议和结果不改写。评价采用主方案第 9.1 节的 `mean-positive-20261031`。2D、005/006、原 VTR 安装均保持冻结。

## 1. 本轮只回答一个主问题

**利用每层资源差异及垂直通道的位置，学习更好的层分配，使后续 GP、APPack、详细布局和布线的节省超过初始化开销。**

预登记主指标是 **计入准备和初始化的冷启动总 runtime**。设计族等权平均相对收益大于零，就记录平均加速；5% 是幅度目标，不要求每个 case 获益，也不要求所有 QoR 指标同时改善。CPD、WL、成功率和失败代价分别完整报告。若只有 QoR 改善，应据实报告该项收益及运行时间代价，不把它改名为实现了本轮加速目标。

006 已证明现有流程能够训练、生成并消费初值，但没有证明性能改善。它的图处理与反馈工程修复继续复用；本轮不以扩大 GNN、增加同配方训练轮数、长时间局部修正或更高初值保持率为目标。

## 2. 三项改动及其边界

### A. 将层分配变成明确的学习任务

```text
网表 APBlock 图＋每层资源/垂直通道图
  → 显式 P(layer | APBlock, device)
  → 资源兼容、fixed 与逐层容量代理检查
  → 选定层内的 P(leaf | layer) 和 XY
  → init.ap.tsv
  → 原生 3D GP → APPack → 原生详细退火 → 布线
```

当前 `model.py` 的监督容量项从联合 leaf softmax 累计层概率，解码却以每层 leaf 分数的 `logmeanexp` 比较层。这在可选 leaf 数不同的层之间不一致。新模型独立输出层分数；监督、容量损失、候选似然代理和硬解码使用同一层语义，不新增连续 Z 回归。

层特征包含各层 LUT/FF/DSP/BRAM/IO 的容量、空间位置、网络连接和垂直接入。保留 molecule/RAM-group 原子性、fixed XYZ、资源 mask 与有界容量分配。AP 需求是 packing 前代理；分配器失败与真实器件不可放置必须分开分类。**不额外执行一次完整 packing 来给初始化提供信息。**

时序输入先复用已有的组合逻辑深度估计，顺序单元作为边界，并保留 driver/sink 方向；明确命名为“逻辑深度时序代理”。它不是 STA slack 或已布局 criticality。最终 CPD 用作实测结果，不作为测试设计的免费输入。缺失/不支持的深度信息显式记录，不通过虚构关键度补齐。

为隔离分层贡献，首轮三种分层方法共用 **一个预训练后冻结的条件 leaf/XY 模块**，包括它自己的编码器、打分器、坐标 head、密度规则和权重哈希。训练层模块不能暗中更新这套 XY 编码器。相同层赋值必须得到相同 XY；不同层导致条件 XY 改变是分层的下游作用。学习层内位置仍保留，但本轮不同时比较三套分别微调的 XY 网络。

### B. 将垂直 TailRisk 加入层分配目标

对垂直资源池 p 定义：

\[
\rho_p=\widehat D_p/C_p,\qquad J_Z=\operatorname{CVaR}_{0.95}(\rho).
\]

`C_p` 是池中独立可用的跨层 RR 资源容量；`D_hat_p` 是候选层/位置下预计占用该池的布线需求。优化含义是减少少数垂直入口过载，**不是要求两层节点数各占一半，也不是把全部跨层连接都消除**。

实现时固定以下定义：

- 空间使用每层 4×4 tile 的叶区域；池按跨层接口、空间足迹、方向、segment 与共享资源归属划分，先于方法结果冻结。双向资源不因两个 arc 计两份容量；不同层端点、串联表示和开关边不能重复充当独立跨层通道。
- 现有 `device_graph.py` 有 pool 容量/足迹，但不能认证完整 pin access。补充定向 RR 接入摘要及池成员映射；保存其可达性证据和近似范围。APBlock 尚未选定具体 site/pin，得到的是候选区域的可达性上界，不是详细布线保证。不能用几何邻接冒充可达性。
- 需求由逻辑网络及候选粗位置投影到可达垂直池。多扇出网络在同一池的共享分支去重，不能把每个 sink 都算作独立占用；时钟/全局网按统一规则处理。普通高扇出网即使不进入 GNN 消息传递，也不能无声地从需求总量消失。
- 使用稀疏候选池与固定预算路径近似，避免 APBlock×全部 RR 节点的稠密张量或逐候选全 RRG 搜索。候选数量、路径近似、遗漏可达资源的处理和复杂度在实现协议中固定；稀疏截断未找到路径只表示“估计器未找到”，不能宣布真实不可达。
- 正需求而零可达容量单列为无通路约束；不以 epsilon 分母掩盖。CVaR 在正容量池上按容量权重计算，P95/P99、最大值及空间非零池数量另报，避免少数很小的池或人为拆池支配结果。接口/方向间的共享资源仍按原 pool ID 去重。
- 同时保存软概率下的期望压力，以及完成硬层分配、一次有限密度处理后的压力。每层反事实 XY 是逐 APBlock 的条件预测，不需要把整个设计强行放进某一层。

两学习臂的共同目标包括教师层监督、层容量代理、时序代理加权 cut/线长以及真实反馈；Tail 臂 **只增加 J_Z 项**。初始 `lambda_Z=0.1`，各项尺度由 train 输入固定归一化，两臂共用归一化表，不根据验证/测试获益调权。精确需求公式、容量成员语义和梯度代理须写入版本化接口并通过小图手算检查，再派发批量任务。

这是一项候选位置相关的供需风险，不更改原有网表 TailRisk Profile 的定义，也不宣称 Escaping Flatland 已验证了这一指标。它的价值由最终结果判断；代理降低但 P&R 不改善，就记录该目标未转化为下游收益。

### C. 只增加一种有界的早期层偏好

比较两种接口：I 仅注入 XYZ；S 注入同一 XYZ，并在早期 Z 求解加入有限二次锚项。

\[
E_Z^{new}=E_Z^{native}+\beta_t\sum_{i\in movable}(z_i-z_i^{init})^2.
\]

首版不使用额外模型置信度加权，避免各生成器的置信度标定成为新变量。第一、第二、第三次真正 GP solve 的相对权重为 `1, 0.5, 0`，之后一直为零；初始化复制不计作一次求解。`beta_0` 取本次原生 Z 系统正对角尺度中位数的 0.1 倍，记录实际值；无有效尺度时报告该条件未启用，不暗中选择别的强度。

只改 Z 的软目标，不锁层、不改 fixed、不改 XY/APPack/SA/router 的优化参数，也不缩短原生停止条件。正常退出前至少执行一次零系数原生求解；若因此多做了迭代，全部计时。系数为零须通过行为回归。

所有七组使用同一个新 binary，Default/I 令 prior 为零。另建隔离后端，不覆盖现有 VTR。原生原型若需要不同数值接口，先更新机器协议并通过正确性检查，不能在性能结果出现后修改衰减规则。

| 编号 | 层分配 | 层内位置 | GP 衔接 |
|---|---|---|---|
| B | 原生 Default | 原生 | 新 binary，prior=0，无自定义初值 |
| D-I | 确定性资源约束、逻辑深度加权分层 | 统一冻结模块 | 仅初值 |
| D-S | 同 D-I，同一初值文件 | 同 D-I | 早期衰减 prior |
| L-I | 显式层 GNN，共同目标 | 统一冻结模块 | 仅初值 |
| L-S | 同 L-I，同一初值文件 | 同 L-I | 早期衰减 prior |

**T-S 对 B 是本轮预登记主比较**；T-I 对 B 同时报告，不能跑完后交换主次。开发阶段可以据完整结果决定下一版本去掉有害 prior，但不能回改本轮主比较。

预登记增量比较：L-I 对 D-I 检查学习分层；T-I 对 L-I 检查垂直 Tail 项；D-S/D-I、L-S/L-I、T-S/T-I 检查衔接；另报告对应软 prior 下的 L-S/D-S、T-S/L-S，观察交互。

D 是“确定性分层＋统一冻结 XY”，**不是完全不含学习的流程，也不是 Escaping Flatland 的完整复现**。确定性层算法只做资源可行的贪心分配与最多两遍增量 cut 改善，每遍扫描次数有界；记录无可行动作/未完成状态，不把它发展为另一个反复调参的布局器。所有方法共用相同容量检查和密度规则。

L/T 从相同共享状态和层模块初始状态训练，使用相同输入、反馈池、样本顺序、训练 seed、epoch 数和选择规则。除 Tail 项外不改变网络宽度、候选预算或损失权重。两个衔接设置逐字节复用同一个 init 文件；最终比较每次调用的完整生成成本仍单独测量，不能把复用用于少计运行时间。

## 4. 训练只做一轮有预算的闭环

1. **复用输入与教师。** 使用已合格 SPMV/MCML 的四 H×Z 架构、两个已校准宽度，以及同签名原生 GP 教师。原始教师不重跑；新特征/代理/投影另存版本，哈希或语义不匹配不能直接沿用旧图。两族都是已暴露 train 族。
2. **共享预训练。** 一次预训练条件 leaf/XY 和新层模块，固定 20 epochs，随后冻结整个 XY 分支；L/T 从相同状态出发，各用对应目标训练固定 5 epochs，生成反馈前候选。T 仅多 Tail 项；不做超参数搜索。共享预训练、两臂候选准备和后续微调的实际成本分别记录。
3. **共同候选池。** 每个条件固定 4 个动作来源：D、L 的初始候选、T 的初始候选、一次固定 seed 的层采样。它们都走同一个有界容量解码/XY 规则；重复动作去重并记录，不不断重采直到遇到好结果。I 模式下用两个反馈 seeds 跑 VPR，L/T 共用全部成功、退化、失败和超时标签。
4. **有界反馈微调。** 两臂各 10 epochs，保存第 5/10 epoch。成功候选按同条件实际后端工作量作排序；相同公共初始化成本不改变其排序，但候选来源 D 的生成耗时不能冒充 GNN 部署成本。保存全部真实准备成本，模型选择及最终比较重新实测端到端总时间。失败/超时单列训练状态，不伪造运行时间、CPD 或 Wmin；成功候选不会因某一 case 的 CPD/WL 超过 3% 就被删掉或统一截成 -1。
5. **用 VPR 选共同 epoch。** active validation 为 blob_merge/diffeq、四架构、参考宽度、两个独立 seeds，使用 I 接口。先按每个 epoch 的 L/T 合计成功数排序，再在四个模型共同成功的固定条件上按两臂平均端到端收益排序，平局取较早 epoch；选择一个共同 epoch，使 Tail 对照不会同时改变训练时长。没有共同成功覆盖时不声称完成了性能选模，保留较早 checkpoint 并标记该限制。缺测不能当失败或收益，须先按预算处理。成功覆盖优先是选模规则，不是重新引入逐 case QoR 研究门槛；训练 loss 不能取代实测。两验证族已有历史暴露，不称最终留族测试。

容量硬解码/VPR 不可微；反馈更新的是实际生成器层分数的排序似然代理，不是只训练一个评分器。两臂的实际参数变化、不同奖励数、排序对数、软/硬分配差异都要保存。

候选全为负仍允许完成这一次有界排序微调和比较，不因缺乏正例无限扩采样。仅有已证实的接口、环境或标签实现故障时，暂停依赖该结果的派发并修复。如果候选去重后无排序对、全部正常不可布通或发生方法自身的解码失败，保留负面/信息不足状态；无有效监督时两臂都不进行反馈微调，使用各自 5 epoch 候选准备后的冻结权重、按单 checkpoint 完成选模记录与开发比较，实际任务数相应减少，明确“反馈训练未发生”。不把无排序对一概当工程故障，也不无限补候选。

## 5. 开发矩阵与预算

SPMV/MCML × H0Z0/H0Z1/H1Z0/H1Z1 × `W_ref/W_stress` × 两个新 backend seeds × 七组 = **224 次开发 P&R**。

相较原提议的 112 次，增加的是预先登记的压力宽度。参考宽度用于主 runtime 比较，压力宽度单独检验成功率/拥塞和性能，不在结果出来后挑有利宽度合并。宽度只继承 Default-only 校准；实际 Z 容量随宽度变化的关系再次从对应 RRG 验证。缺少有效压力点的条件标为缺失，不能从模型效果反选宽度凑矩阵。

| 工作 | 上限/数量 | 目的 |
|---|---:|---|
| 新接口小测 | 最多 12 次小 P&R | 3 类 fixture × I/S × 2 seeds：单层、双层均衡、异构/固定层；新 prior、消费与恢复检查 |
| 反馈采集 | 160 次 | 2 族 × 4 架构 × 2 宽度 × 2 seeds ×（4 个候选＋Default） |
| checkpoint 选择 | 80 次 | 2 validation 族 × 4 架构 × 1 宽度 × 2 seeds ×（2 模型 × 2 checkpoints＋Default） |
| 七组开发比较 | 224 次 | 上述主矩阵，含同期 Default |
| 合计 | **最多 476 次** | 其中 464 次研究 P&R；GPU 训练、RRG/结构导出和非 P&R 单测成本单列 |

预留随机源：接口 2701/2702，反馈 2721/2722，选模 2741/2742，开发比较 2761/2762，模型 2801。协议检查 split、seed 和输入签名；相同 seed 的参数变体不构成独立设计。重复动作可以减少派发数，但不得悄悄给某模型增加样本。上述上限不含基础设施故障重试；确认修复后每条件最多一次，所有重试成本另记，不能借重试更换方法或搜索预算。

已有同签名数据可复用做教师与正确性证据；**正式 runtime 比较的 Default 同期重跑**，不能拿历史不同 host/并发的时间当对照。全部失败、超时和解码失败保留。缺失可能改变结论时标为未完成，不只平均幸存的有利 case。

这批比较覆盖两个已训练设计族，只用于开发归因。不能称未见设计泛化，也不产生 Wmin 结论。开发结束后，若出现值得复验的平均收益，冻结模型/接口，再做历史暴露审计后的独立设计验证；扩展阶段只保留 Default、对应 D、选定学习方法三个部署臂，避免把全部组件开发预算重复一遍。正式数量由合格且未暴露的族数决定，按四架构、双宽度、五 seeds、三方法计为每族 120 次，预先生成任务表。

## 6. 结果必须解释收益从哪里来

每个方法记录：

- 完整准备、模型加载/前向、解码、文件生成、GP、APPack/packing、详细布局、routing 与总 wall time；冷调用为主，常驻调用单独报告。
- GP 外层/CG 工作量、packing 尝试、router 迭代及阶段用时。未暴露的计数增加轻量 hook；不可用则标缺失，不能由总时间反推。
- init、GP 后、APPack 后、详细布局后的层变化。通过 atom/APBlock 对应做统计，不能直接比较数量不同的 packed cluster ID。固定层违规与正常优化改层分开。
- 每个候选预测的垂直 pool 压力；router 第一轮及最后一轮的实际垂直 RR 占用、超用和利用率尾部，以及最终跨层资源使用量。成功布线的最终 overuse 通常为零，不能单独拿它验证风险指标。
- CPD、WL、成功/不可布通/超时/其他失败、所有逐例比值、H/Z 面板、胜平负与退化尾部。

主 runtime 按主协议族内、族间等权几何比汇总，`G=1-R`；`G>0` 即平均正收益。共同成功子集的结果注明覆盖与条件性；失败更快退出不算加速。区间和每族结果用于表述不确定性，不恢复逐 case 必胜或统一显著性硬门槛。

同时给出三类明确结论：

1. **层/Tail 改动减少后端工作且总时间获益：**支持当前初始化方向，进入独立族复验。
2. **后端/QoR 有改善、但总时间没有：**保留该项实际收益和成本，不能宣称完成加速。若决定改为 QoR 主线，下一批先登记主指标与时间预算，不回改本轮。
3. **只有 Tail 数值或初值保持率改善：**代理机制未兑现，不继续用增加迭代、候选或训练 epochs 来拖延结论。

Wmin 另行测量，不阻塞本轮已测指标的结论。用于百分之几差异的正式扫描要粗定位后补测边界内所有合法相邻宽度，核验实际合法步长；每 seed 的最小成功宽度先求均值，再跨族汇总。固定 `.place` route-only 与每宽度全流程重跑分开，不能从两个压力点推断精确 Wmin。

## 7. 开发交付顺序、并行与清理

第一轮代码按三个可并行工作包完成，然后只做一次集成检查：

| 工作包 | 交付 | 边界 |
|---|---|---|
| 模型/训练 | 独立层 head、统一概率语义、冻结条件 XY、共同反馈训练 | 不改 2D；不在测试集求梯度/选模；不扩大网络 |
| 器件/后端 | 可达垂直池摘要、需求估计、衰减 Z prior、层/路由计数 | 固定 40f8 基础；不改原生 SA/router 策略；不覆盖原安装 |
| 协议/评估 | 七臂任务表、`mean-positive` 新评估、续跑与清理账本 | 新 cohort；不可重新解释 003–006 的 `passed` |
