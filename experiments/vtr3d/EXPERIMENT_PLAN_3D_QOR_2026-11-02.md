# 009：以 WL / CPD 为主目标的 3D 初始化实验

日期：2026-11-02。状态：**计划已冻结为下一轮设计依据，算法与运行入口尚未实现，实验尚未启动。** 新策略标识 `qor-first-20261102`，新输出 `development_009_qor`。本计划替代旧计划中针对后续实验的runtime优先目标；003–008的代码、协议与结论继续按原口径保存。

## 1. 目标与判定

研究问题改为：**学习层分配和层内位置，利用异构资源及垂直连接，在相同器件和后端上降低最终布线线长与关键路径时延。** 允许增加计算时间，收益不能靠给某方法更多布线资源获得。

| 优先级 | 指标 | 用途 |
|---|---|---|
| 第一 | 最终 routed WL、CPD | 共同主要目标；训练偏好、验证选模和主要结果 |
| 第二 | Wmin、实际纵向资源占用、最小已测可用纵向配置容量 | 检查可布线性与资源效率；用专门实验测量 |
| 第三 | 总runtime、峰值内存及训练成本 | 成本与可扩展性；不再以加速作为QoR成功的前提 |

用户没有指定WL/CPD内部优先级，本轮按**等权**处理。对同条件成功候选A/B，先在相同seeds上分别算术平均，再计算：

\[
q(A,B)=\tfrac12\log(\overline{WL}_A/\overline{WL}_B)
       +\tfrac12\log(\overline{CPD}_A/\overline{CPD}_B).
\]

`q<0`用于联合偏好和选模，同时始终保存两个分量及Pareto状态。最终逐设计/架构先对5 seeds算术平均，再计算方法/Default比值；四架构等权、设计族等权取几何平均，得到`R_WL`和`R_CPD`。这是009事前冻结的新口径，008原有seed配对几何平均不重写。

- 两个总体比值均不大于1、至少一个小于1：平均联合改善。
- 一个改善、另一个退化：报告明确的QoR取舍和联合分数，不能写成两项同时改善；仍可构成单项贡献。
- 两个均退化：没有主目标收益，即使runtime或Tail代理改善也不能改写这个判断。
- 允许个别case退化，不恢复逐case 3%否决，也不要求至少5%收益。报告所有逐例结果、架构分组、胜负及族级区间；两训练族的区间仅为描述性证据。
- 缺测/超时/不可布通分别列出；失败不填虚构WL/CPD。共同成功子集的均值明确其覆盖范围，成功覆盖下降不能隐藏为全体QoR优势。

runtime只报告代价，主要分数相同才作最后择优。保留原有单任务3600秒等资源上限作为执行预算，不将其变成“方法必须更快”的论文判据。

## 2. 现有事实及论文启发

008已修复教师/硬解码一致性，但主T-S/B为CPD−0.48%、WL+2.23%，不能因为现在改目标就追溯宣称008成功。其训练偏好与选模仍按runtime，XY又被冻结。新的只读重排发现：42对成功可比候选中，**18对的WL/CPD联合优劣与runtime排序相反**；20对两指标同向，22对存在取舍。另6对是成功次数差异，48对共同失败没有QoR标签。见[重排诊断](QOR_RELABEL_AUDIT_2026-11-02.json)，未新增P&R。

[Escaping Flatland](https://arxiv.org/html/2604.01078v1) §5.1/5.2使用CPD、routed WL及Pareto比较；§5.3在3D CB上报告总runtime约+12%，主要增加来自partition。论文的完整收益同时包含分层、时延模型、代价调度和move set，不能只归因于初始化。其分层使用packing后blocks及packer criticality；我们的prepack APBlock没有免费获得这类时序信息。其Wmin是10 seeds的均值，正文未说明步长或固定.place细节；不能从2.82%推断步长1。

本轮借鉴真实QoR反馈与多目标评价，固定现有VPR后端及其正常优化流程。若后续加入论文的时延模型/SA改动，另以“初始化×后端”2×2矩阵归因，不能与本轮GNN改动捆绑后只宣称初始化收益。

## 3. 一次安排好六组对照

全部使用固定40f8基础上的现有合格3D binary，GP→APPack→原生详细退火→route，`layer_prior=0`（I接口）。不重复007/008的I/S全交叉。分层与叶区域/XY的共同容量、fixed、molecule和有界密度解码规则一致。

| 方法 | 真实反馈目标 | 层内模块 | 原`.1*cut`惩罚 | 垂直Tail项 |
|---|---|---|---|---|
| B | 原生Default | 原生 | 原生 | 无 |
| R | 008式runtime偏好，匹配新训练预算 | 冻结 | 保留 | 无 |
| Q | WL/CPD偏好 | 同一冻结模块 | 保留 | 无 |
| C | 同Q | 同Q | 去掉，只记录cut | 无 |
| X | 同C | 训练条件leaf/XY | 去掉 | 无 |
| T | 同X | 同X | 去掉 | CVaR正则 |

预登记主比较为 **T/B**，X/B是主要辅助比较。Q/R识别目标更换；C/Q识别直接跨层计数惩罚的影响；X/C识别扩大到层内坐标动作及其有效反馈的完整学习路径；T/X识别Tail增量。X/C包含动作支持域变化，不声称只是多解冻几个参数的单因素收益。R是匹配预算的runtime控制，不能用额外训练的新方法去对比完全不训练的旧权重，然后把差异全归因于目标。

R/Q/C/X/T从同一个008候选准备L checkpoint复制参数，初始模型、图、教师、batch顺序、原始候选池和优化预算相同；各臂可学习动作的过滤规则见4.2，不能宣称过滤后的有效对数必相等。R/Q/C冻结相同XY；X/T从同一XY权重开始更新。X/T既有的区域与坐标head使用相同结构。除表中因素外，其他损失权重、已有XY几何代理与解码规则相同；不同时扩网络、改后端温度或引入长搜索。

当前跨层cut直接计数惩罚可能鼓励单层集中，而有益垂直连接可以缩短长XY路径。C/Q专门验证此点，不强制两层50/50。Tail表达局部垂直需求/容量尾部，不等于最少跨层网络数；首版沿用train教师归一化和`lambda_tail=0.1`，只在T中添加，验证选择仍只看主要QoR，不靠Tail数值下降选优。

## 4. 训练、反馈和选模

### 4.1 直接复用现有信息

复用008的24个派生教师、图/约束、原始候选动作、真实CPD/WL、状态与来源hash，不重采相同的160次P&R。**仅16个train条件进入loss及归一化尺度，8个active-validation条件仅审计/选模，不进入训练。** 全部负收益和失败保留。旧runtime标签及选择记录只读，新建`qor_preferences.json`等009数据。

新偏好以同条件、相同backend seeds为前提。成功次数不同先形成独立的可布通性偏好；成功seed集合相同且非空时再按q排序；相同成功次数但成功seed集合不同，不伪造QoR排名。Q/C/X/T按train非零`|q|`中位数统一归一化，R也按同一规则用train非零`|log(runtime比)|`中位数归一化；均上限截为5、保存原值，避免Q/R同时混入是否缩放奖励的区别。成功次数偏好权重统一1，反馈loss系数统一0.2。尺度在新候选采集前冻结，四个QoR臂共用其尺度，不根据验证/测试改权重。

### 4.2 给层内坐标真正的反馈

现有`action_log_probability`只含layer，单纯更换奖励不会训练XY。009对固定候选`a=(layer,leaf,xy)`使用以下动作评分代理（对movable AP取平均，固定坐标轴不计坐标误差）：

\[
s_\theta(a)=\operatorname{mean}\log p_\theta(layer)
+\operatorname{mean}\log p_\theta(leaf\mid layer)
-\frac{1}{2\sigma^2}\operatorname{mean}\left\|\frac{f_\theta(layer,leaf)-xy}{leaf\_extent}\right\|^2,
\quad\sigma=0.25.
\]

`f_theta`在候选指定的整组层/叶分配下输出经同一有界密度混合的XY。候选layer/leaf/xy是固定监督目标，**当前模型的条件坐标forward必须保留梯度，不能把`decode_action`返回的no_grad硬XY拿来当坐标训练输出。** 以`w*softplus(-(s_better-s_worse))`更新；它是离策略评分代理，不宣称为容量约束动作的精确概率。X/T更新坐标及区域参数，R/Q/C相同子模块冻结。必须验证坐标head收到非零梯度、参数和实际输出改变。

候选奖励作用于**实际部署生成器**。不把一个额外评分网络训练成功算作坐标生成器改善。风险前向仍使用真实硬解码动作；离散选择/容量/VPR不求精确梯度。训练梯度近似、哪些head接收梯度和最终输出是否变化必须记录。

X/T更新XY后，历史动作来自旧policy属于离策略监督。保留collection checkpoint、decoder、shared-XY和constraint hash；通过独立adapter验证历史动作的可达性和容量，再生成009偏好引用。不能简单改旧schema、删掉hash检查，或要求历史动作必须来自当前正在改变的XY权重。

共用原始库不等于每臂能学习全部动作。R/Q/C的actor偏好只使用相同冻结XY/decoder支持的动作（兼容008与新R/Q/C）；X/T可使用所有经约束验证的历史动作。相同layer/leaf而只XY不同的候选，不能给冻结坐标臂伪造层选择梯度。各臂保存有效对数、来源及过滤原因；X/C的动作支持域差异事前声明，T/X则严格使用同一有效池。

### 4.3 一轮有界训练

1. 先用旧标签训练R/Q/C/X/T各5 epochs，不采新教师。
2. 仅在train的8个reference条件（SPMV/MCML×四架构）上各生成五个新动作，配同期Default及两个seeds：`8×(5+1)×2=96`次P&R。五臂共用原始新旧标签库，依4.2过滤actor可学习动作；重复动作去重记录，不无限补样本。旧stress标签保留，本轮不向已饱和失败点重复投入反馈预算。
3. 五臂各反馈微调10 epochs，保存第5/10 epoch；相同训练顺序与预算，禁止按某臂结果追加epochs。
4. active validation仍为blob_merge/diffeq×四架构×已冻结reference宽度×两个seeds。五臂各两个checkpoint及一个Default：`8×2×(5×2+1)=176`次P&R。
5. X/T先按合计成功覆盖比较两个epoch，再在共同成功的固定条件上用两臂平均q选一个**共同epoch**；平局取较早。R/Q/C也使用该epoch，均完整报告验证结果。runtime只在主要量数值相同时作末级参考，不因测试结果改选。

预留seed：训练9301；新反馈9101/9102；验证9201/9202；开发比较9001–9005；Wmin范围校准9901。实现时检查全历史seed/族暴露表，发现重复在结果产生前改登记。已有008反馈seeds按来源保留。

## 5. 首轮WL/CPD主实验

**2族×4架构×1公共宽度×5 seeds×6方法＝240次P&R。** 加反馈96和选模176，首轮共**最多512次研究P&R**。自然设计仍为已训练SPMV/MCML，用于开发归因；不是未见族测试。

公共`W_qor`固定为SPMV128、MCML224，继承008 Default校准；所有方法使用同一XML、grid、SDC、引脚/固定约束、RRG与router预算。blob_merge/diffeq的验证宽度同样直接继承冻结清单。不得按各方法自己的Wmin分别设置QoR宽度；失败也不得单方扩宽后混入主表。

全部四H×Z架构保留，总逻辑资源、总Z容量相同，H只改变按层资源分布、Z只改变纵向入口空间分布；从真实RRG复核。五seeds是本轮开发精度，后续独立族正式表计划10 seeds，不能把五次宣称为论文的10次复现。

冻结指标：`WL_VPR`（当前日志Total wirelength）、最终CPD、完整状态/覆盖，以及实际Z用量。实施前用小图和固定版本源码核对`WL_VPR`对CHANZ的计数语义；另记XY tile-span、Z hops，不在没有tile pitch/层距时称物理微米总长度。多扇出共享分支按每net的RR节点去重，不按sink重复计线长/纵向占用。CPD来自相同后端时序模型，并记录时序约束与异常；几何代理不冒充STA。

记录逐阶段GP/APPack/SA/route、冷/常驻成本与内存，但不以少迭代或初值保持率作为主要成功条件。约束和中间摘要落盘后及时清理不再用的`.net/.net.post_routing/.route`及重复图；route内需要的WL/Z摘要必须先提取，后续训练动作/权重保留。

## 6. Wmin：另做真实细网格

冻结模型后，在事先指定的H0Z0、H1Z1两架构上比较B/T，不能按首轮结果挑架构或换主模型。

1. 对每族/架构用Default与专用seed9901，从008的stress/reference宽度开始，最多8个宽度粗定位，共最多32次；只确定范围。`Wc`是这次粗定位中已观察到的最小成功合法宽度，不是区间中点，也不声称它已经是Wmin。合法中点缩小已观察失败/成功区间只用来选范围，最终网格仍全测；8次后无成功锚点或存在影响范围的unknown时标`calibration_unresolved`，不虚构Wc或无限扩跑。优先复用同签名已有Default证据。
2. 按固定VPR的横向directionality及真实RRG确定合法间隔`delta`，不能猜1，也不能把Z双向文件名当XY双向。通常单向有偶数要求，以实际工具为准。
3. 在粗定位中心`Wc`附近冻结最多17个相邻合法宽度的公共网格（初始`Wc-12*delta`到`Wc+4*delta`，下界裁到合法最小值）。B/T对所有网格点均跑完整GP→APPack→SA→route，不假设一次失败后更小宽度必失败。
4. 定义`Wmin_grid(method,seed)=min{网格内完整成功宽度}`。每design/arch先对9001–9005五seeds算术平均，再报族等权比值。请求宽度与实际宽度同时保存；无成功、触及下界或unknown导致边界不明时报告删失/区间，不强填一个Wmin，也不无限扩网格。

上限为`2族×2架构×5 seeds×2方法×17点=680`次，加最多32次范围校准。可复用完全同签名已有点，实际新增数单列。该值是**指定网格及算法下的观察最小成功宽度**，不是全域数学最优。固定.place的route-only扫描若另做，应标`Wmin_route`，不能替代本轮完整流程`Wmin_grid`。

既有64×64和84×84实际RRG显示已测宽度内connected CHANZ容量分别恒为5766/10086，但新细点仍须核验`C_Z(W)`及方向/segment构成。若增宽同时增加Z供给，必须将Wmin结果解释为联合资源预算变化，不能写成纯横向节省。

## 7. 纵向资源：区分实际用量和配置供给

主实验直接记录最终成功路线的：全局唯一CHANZ节点、每(net,RR-node)占用、每pool利用率、方向/segment组成。容量为1时唯一节点数可代表占用；容量大于1必须记录slot occupancy。同一net多个sink共享的Z资源只计一次。首轮路由CVaR/overuse只作机制诊断，不能代替最终实际用量。

若要声称器件可少配置纵向资源，另做固定XY宽度的配置扫描。现有`architectures.generate_architecture`支持`z_per_location`；在H1Z0/H1Z1固定位置集合及逻辑资源下用`{6,4,2}`，复核真实connected独立容量、方向、segment/switch及可达性。不随机删除RR边。

比较B/T，两设计、两个预定架构、五相同seeds；6档复用主实验，4/2档新增`2×2×5×2×2=80`次P&R。每档完整报告WL/CPD、成功覆盖和实际Z用量，得到“最小已测可用Z配置预算”。少用Z节点不直接等于相同比例TSV面积或制造成本节省。Wmin扫描固定Z，Z扫描固定W，避免同时减少两类供给而无法归因。

## 10. 论文扩展与外部比较

开发通过后先冻结方法/权重，再依据完整暴露记录选择尚未用于训练/选模的设计族；不同参数和随机seed仍属同族。正式规模由合格独立族清单决定，预定10seeds，族数如不足如实报告，不能把SPMV/MCML或已反复查看的validation称未见测试。

VTR同后端是算法主对照。Beyond Flatland保留完整作者流外部对照；可适配且同架构/时序模型才给直接算法比较，否则标系统级差异。Vivado继续按既有7系列近似资源参照，报告功能、资源和模型差异；不是自定义异构3D的同芯片对照，不用跨器件绝对CPD归因于初始化。两条外部支线不占本轮512预算，也不阻塞内部主实验。
